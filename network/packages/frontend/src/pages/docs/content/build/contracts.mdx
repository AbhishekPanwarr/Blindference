## Key Contracts for Builders

<Accordion title="PromptKeyStore">
  The most important contract for agent developers. Stores CoFHE-encrypted AES key halves.

  #### storeKey()

  Stores CoFHE-encrypted key halves on-chain.

  ```solidity title="PromptKeyStore.storeKey()"
  function storeKey(
      uint256 kpHighHandle,  // CoFHE ciphertext handle for high 128 bits
      uint256 kpLowHandle    // CoFHE ciphertext handle for low 128 bits
  ) external returns (uint256 keyId);
  ```

  **Usage**:
  - Called by user wallet (frontend)
  - Grants ACL to the calling address
  - Returns a unique `keyId` for later retrieval

  #### getKey()

  Retrieves stored key handles.

  ```solidity title="PromptKeyStore.getKey()"
  function getKey(uint256 keyId) external view returns (uint256 kpHighHandle, uint256 kpLowHandle);
  ```

  #### decryptForView()

  Decrypts a stored handle using a sharing permit.

  ```solidity title="PromptKeyStore.decryptForView()"
  function decryptForView(uint256 handle) external view returns (uint256 plaintext);
  ```

  <Info>
    This is a view function that calls the CoFHE threshold network. Requires a valid sharing permit for the caller.
  </Info>
</Accordion>

<Accordion title="ResultRegistry">
  Records accepted and rejected inference outcomes.

  #### commitResult()

  Commits an accepted inference result.

  ```solidity title="ResultRegistry.commitResult()"
  function commitResult(
      bytes32 taskId,
      bytes32 resultHash,
      address leader,
      address[] calldata verifiers,
      bool accepted
  ) external;
  ```

  #### getResult()

  Retrieves a committed result.

  ```solidity title="ResultRegistry.getResult()"
  function getResult(bytes32 taskId) external view returns (
      bytes32 resultHash,
      address leader,
      bool accepted,
      uint256 timestamp
  );
  ```
</Accordion>

<Accordion title="ExecutionCommitmentRegistry">
  Tracks task dispatch and deadlines.

  #### dispatch()

  Dispatches a task to a leader and verifier.

  ```solidity title="ExecutionCommitmentRegistry.dispatch()"
  function dispatch(
      bytes32 invocationId,
      uint256 escrowId,
      bytes32 agentId,
      address executor,
      address crossVerifier,
      uint256 commitDeadline,
      uint256 revealDeadline
  ) external;
  ```
</Accordion>

<Accordion title="ReputationRegistry">
  Tracks operator performance.

  #### reputationOf()

  Returns an operator's reputation score.

  ```solidity title="ReputationRegistry.reputationOf()"
  function reputationOf(address operator) external view returns (
      uint256 score,
      uint256 tasksAccepted,
      uint256 tasksRejected,
      uint256 totalSlash
  );
  ```
</Accordion>


## Interaction Patterns

### Pattern 1: Store and Retrieve Key

```typescript title="Store and retrieve key"
// 1. User stores key
const tx = await promptKeyStore.storeKey(kpHighHandle, kpLowHandle);
const receipt = await tx.wait();

// 2. ICL reads stored handles
const [high, low] = await promptKeyStore.getKey(keyId);

// 3. Node decrypts with permit
const decrypted = await promptKeyStore.decryptForView(high)
  .withPermit(nodePermit);
```

### Pattern 2: Verify Result

```typescript title="Verify committed result"
// Check if a result was committed
const result = await resultRegistry.getResult(taskId);
if (result.accepted) {
  console.log(`Result accepted by leader ${result.leader}`);
}
```

### Pattern 3: Check Node Reputation

```typescript title="Check node reputation"
const rep = await reputationRegistry.reputationOf(nodeAddress);
console.log(`Score: ${rep.score}, Accepted: ${rep.tasksAccepted}`);
```

## Deployment

To deploy your own instance (for testing):

```bash title="Deploy PromptKeyStore"
cd network/packages/contracts
source .env

forge script script/DeployPromptKeyStore.s.sol:DeployPromptKeyStore \
  --rpc-url $ARB_SEPOLIA_RPC \
  --broadcast \
  --verify \
  --etherscan-api-key $ARBISCAN_API_KEY
```
