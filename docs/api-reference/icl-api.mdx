# ICL API

The Inference Coordination Layer (ICL) exposes a REST API for submitting requests, tracking status, and managing the inference lifecycle.

## Base URL

| Environment | URL |
|-------------|-----|
| Production | `https://icl.blindference.xyz` |
| Local Development | `http://127.0.0.1:9000` |

## Authentication

Most endpoints are public (read-only). Write endpoints (submit request) use the `developer_address` field for authorization (signed by the user's wallet via MetaMask transactions).

<Info>
  The ICL never asks for private keys. Authorization is implicit via on-chain transaction signatures.
</Info>

<Card title="GET /v1/inference/quorum-preview" icon="search">

## Status Values

| Status | Meaning | Next Action |
|--------|---------|-------------|
| `QUEUED` | Request received, quorum not yet completed | Poll every 5s |
| `ACCEPTED` | Quorum consensus reached (2/3 match) | Decrypt output, reveal result |
| `REJECTED` | Quorum failed (<2/3 match) | Check dispute process |
| `DISPUTED` | Result disputed, under review | Wait for resolution |
| `TIMEDOUT` | Execution window expired | Resubmit or refund |

## Error Responses

| Status Code | Meaning | Resolution |
|-------------|---------|------------|
| 400 | Invalid request body | Check request schema |
| 404 | Request not found | Verify request_id |
| 409 | Request already exists | Use existing request_id |
| 422 | Validation error | Check field types |
| 500 | Internal server error | Retry or contact support |
| 502 | ICL dependency error | Check ICL health |

## Rate Limits

| Endpoint | Limit |
|----------|-------|
| Quorum preview | 10 requests/minute per IP |
| Submit request | 5 requests/minute per address |
| Status polling | No explicit limit (use ~5s intervals) |

## SDK Clients

<Tabs>
  <Tab title="Python">
    ```python title="Python ICL client"
    import requests

    class ICLClient:
        def __init__(self, base_url: str = "https://icl.blindference.xyz"):
            self.base_url = base_url

        def get_quorum_preview(self, model_id: str, min_tier: int = 0, verifier_count: int = 2):
            return requests.get(
                f"{self.base_url}/v1/inference/quorum-preview",
                params={"model_id": model_id, "min_tier": min_tier, "verifier_count": verifier_count}
            ).json()

        def submit_request(self, payload: dict):
            return requests.post(
                f"{self.base_url}/v1/inference/requests",
                json=payload
            ).json()

        def get_status(self, request_id: str):
            return requests.get(f"{self.base_url}/v1/inference/{request_id}").json()
    ```

  <Tab title="TypeScript">
    ```typescript title="TypeScript ICL client"
    class ICLClient {
      constructor(private baseUrl: string = 'https://icl.blindference.xyz') {}

      async getQuorumPreview(modelId: string, minTier = 0, verifierCount = 2) {
        const params = new URLSearchParams({ model_id: modelId, min_tier: String(minTier), verifier_count: String(verifierCount) });
        const res = await fetch(`${this.baseUrl}/v1/inference/quorum-preview?${params}`);
        return res.json();
      }

      async submitRequest(payload: any) {
        const res = await fetch(`${this.baseUrl}/v1/inference/requests`, {
          method: 'POST',
          headers: { 'Content-Type': 'application/json' },
          body: JSON.stringify(payload)
        });
        return res.json();
      }

      async getStatus(requestId: string) {
        const res = await fetch(`${this.baseUrl}/v1/inference/${requestId}`);
        return res.json();
      }
    }
    ```
