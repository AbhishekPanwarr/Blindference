# Monitoring

You have two ways to monitor your node: the **web-based Node Dashboard** (in the frontend) and the **CLI monitoring commands** (in the terminal).

## Node Dashboard (Web)

The fastest way to see your node's status is through the web dashboard.

### Access

1. Open the Blindference frontend (http://localhost:3000)
2. Connect your MetaMask wallet
3. Click **"Node Dashboard"** in the sidebar (appears only when your wallet is connected)

### What You See

The dashboard shows a real-time summary of your node's performance:

| Card | Shows |
|------|-------|
| **Current Stake** | On-chain BLIND stake (live from BlindferenceStaking contract) |
| **Total Earned** | Cumulative BLIND rewards across all completed jobs |
| **Jobs Completed** | Total jobs, with success vs. failed breakdown |
| **Success Rate** | Percentage of jobs completed successfully |

Below the stats cards, you'll find:

- **Job History table** — Every job you've participated in (leader or verifier), with:
  - Job ID
  - Role (leader/verifier)
  - Status (COMPLETED, FAILED, RUNNING, REFUNDED)
  - Model used
  - BLIND earned
  - Completion time
- **Node Status panel** — Active/Inactive, consecutive failures count, slashed status
- **Reward Split legend** — Leader gets 60%, each verifier gets 20%

### Slash Warnings

If your node approaches the slash threshold (3 consecutive failures), a red warning banner appears:

> ⚠️ Warning: Slash Risk — Consecutive failures: 2/3. One more failure and your stake will be hard-slashed on-chain.

### Non-Operator View

If your connected wallet is **not** a registered operator, the dashboard shows a **Become a Node** banner with setup instructions and a link to the PyPI package.

## Log-Based Monitoring

### Local Node Logs

```bash
# Tail logs in real-time
tail -f ~/.blindference/node.log

# Or if running in foreground, logs go to stdout
grep -E "ERROR|WARNING" ~/.blindference/node.log
```

### Key Metrics from Logs

```bash
# Total jobs received
grep "Received.*assignment" node.log | wc -l

# Jobs by role
grep "starting as leader" node.log | wc -l
grep "starting as verifier" node.log | wc -l

# Job outcomes
grep "Leader result accepted" node.log | wc -l
grep "Verdict: match" node.log | wc -l
grep "Verdict: no-match" node.log | wc -l

# Inference performance (DEBUG level)
grep "Inference complete" node.log | awk '{print $NF}' | sort -n | awk '
  {sum+=$1; count++}
  END {print "Avg:", sum/count, "ms"}'
```

### Heartbeat Health

```bash
# Count heartbeats in last hour
grep "Heartbeat sent" node.log | wc -l
# Expected: ~60 (1 per minute)

# Count heartbeat failures
grep "Heartbeat failed" node.log | wc -l
# Expected: 0
```

## Alerting

### Simple Shell Script

```bash
#!/bin/bash
# check_node_health.sh

HEALTH=$(curl -s -o /dev/null -w "%{http_code}" $BLF_ICL_ENDPOINT/health)
if [ "$HEALTH" != "200" ]; then
  echo "ALERT: ICL health check failed with status $HEALTH" | mail -s "Blindference Alert" admin@example.com
fi

# Check if node is in active pool
ACTIVE=$(curl -s "$BLF_ICL_ENDPOINT/v1/nodes/active" | grep -c "your_address")
if [ "$ACTIVE" -eq 0 ]; then
  echo "ALERT: Node not in active pool" | mail -s "Blindference Alert" admin@example.com
fi
```

Run via cron every 5 minutes:

```bash
*/5 * * * * /path/to/check_node_health.sh
```

### Prometheus / Grafana (Advanced)

For production deployments, expose metrics in Prometheus format:

```python
# Add to node_loop.py
from prometheus_client import Counter, Histogram, start_http_server

jobs_completed = Counter('blindference_jobs_completed', 'Jobs completed', ['role'])
inference_duration = Histogram('blindference_inference_seconds', 'Inference duration')
heartbeat_failures = Counter('blindference_heartbeat_failures', 'Heartbeat failures')

# Start metrics server
start_http_server(9090)
```

Then scrape with Prometheus and visualize in Grafana.

## ICL Health Check

```bash
curl -s $BLF_ICL_ENDPOINT/health | python3 -m json.tool
```

Expected response:

```json
{
  "status": "ok",
  "chain_connected": true,
  "database_connected": true
}
```

### Node Status via ICL

```bash
# Check if your node is in the active pool
curl -s "$BLF_ICL_ENDPOINT/v1/nodes/active" | python3 -m json.tool | grep -A5 "your_address"

# Check node metrics
curl -s "$BLF_ICL_ENDPOINT/v1/nodes/{your_address}" | python3 -m json.tool
```

Expected metrics:

```json
{
  "operator_address": "0xdDef3Cf5A4d0A6404Bc084D74de3E2c0d6147dA5",
  "model_tiers": [0],
  "active": true,
  "tasks_completed": 42,
  "tasks_accepted": 40,
  "tasks_rejected": 2,
  "last_heartbeat": 1779078687
}
```
