# Quickstart

Get a Blindference node running and earning in under 5 minutes.

## Prerequisites

- Python 3.10 or higher
- pip (Python package manager)
- A terminal with internet access
- No GPU required for mock inference

<Info>
  No GPU? No problem. Tier-0 nodes can use cloud APIs (Groq, Gemini) for inference.
</Info>

## Install

<Tabs>
  <Tab title="PyPI (Recommended)">
    ```bash title="Install from PyPI"
    pip install blindference-node
    ```

    For GPU-accelerated local inference (optional):

    ```bash title="Install with GPU support"
    pip install "blindference-node[gpu]"
    ```
  </Tab>
  <Tab title="From Source">
    ```bash title="Clone and install"
    git clone https://github.com/baync180705/Blindference-node.git
    cd Blindference-node
    pip install -e .
    ```
  </Tab>
  <Tab title="Docker">
    ```bash title="Run with Docker"
    docker build -t blindference-node .
    docker run -e BLF_KEY_PASSWORD=secure_password \
      -e BLF_ICL_ENDPOINT=https://icl.blindference.xyz \
      blindference-node run
    ```
  </Tab>
</Tabs>

## Initialize

```bash title="Initialize your node"
blindference-node init
```

This smart command checks your environment first:

<Steps>
  <Step title="Detects env vars" icon="scan">
    If `BLF_PRIVATE_KEY` is set, auto-imports wallet (no prompt)
  </Step>
  <Step title="Detects GPU" icon="cpu">
    Checks for NVIDIA GPU and vLLM availability
  </Step>
  <Step title="Detects API keys" icon="key">
    If `GROQ_API_KEY` or `GOOGLE_API_KEY` set, includes cloud models
  </Step>
  <Step title="Prompts missing fields" icon="message-circle">
    Wallet creation, password, API keys — only what's needed
  </Step>
  <Step title="Saves configuration" icon="save">
    Writes `~/.blindference/config.json`
  </Step>
</Steps>

## Attest Your Node

<Warning>
  You must attest before running. The daemon will exit with an error if no valid attestation certificate is found.
</Warning>

```bash title="Interactive attestation"
# Interactive attestation (choose mock or TEE)
blindference-node attest
```

```bash title="Mock attestation (development)"
# Or skip interactive menu and use mock directly
blindference-node attest --mock
```

```bash title="Custom dev key"
# Or with custom development key
blindference-node attest --mock --tee-key mydevkey
```

### Interactive Attestation Flow

```bash title="Interactive prompt"
Attestation type:
  [1] Mock (development)
  [2] TEE / TPM (production)
Select [1]:
```

- **Option 1 (Mock)**: Uses `weloveblindference` key — fastest, no hardware needed
- **Option 2 (TEE)**: For production hardware attestation (SGX/TDX/TPM)

### On-Chain Registration (Optional)

After ICL attestation, the CLI asks:

```bash title="On-chain registration prompt"
Do you want to register on-chain? [Y/n]:
  → Gas estimate : 487,231 units
  → Est. cost    : 0.000058 ETH
  → Send registration transaction? [Y/n]:
```

Mock/development tiers can skip this. Production tiers require it.

## Start the Daemon

```bash title="Start the daemon"
blindference-node run
```

Enter your keystore password when prompted. The daemon starts four concurrent loops:

| Loop | Frequency | Purpose |
|------|-----------|---------|
| ICL Heartbeat | Every 60s | Proves liveness to ICL (free REST call) |
| On-Chain Heartbeat | Every 10 days | Proves liveness to NodeRegistry (gas tx) |
| Attestation Watchdog | Every 10min | Auto-re-attests if certificate expires within 6h |
| Assignment Poller | Every 5s | Polls ICL for pending inference jobs |

## Verify

Check that your node is registered:

```bash title="Check node status"
blindference-node status
```

You should see your node address, tier, models, attestation status, and cert expiry.

To check active nodes on the ICL:

```bash title="List active nodes"
curl -s http://127.0.0.1:8000/v1/nodes/active | python3 -m json.tool
```

## Monitor Earnings

Once jobs start completing, check your progress:

```bash title="List recent jobs"
# List recent jobs with earnings
blindference-node jobs list --limit 10
```

```bash title="Check total earnings"
# Total BLIND earned
blindference-node jobs earnings
```

```bash title="Check staking status"
# Check on-chain stake and slash risk
blindference-node staking status
```

```bash title="Check BLIND balance"
# BLIND token balance
blindference-node balance
```

You can also view a live **Node Dashboard** in the web frontend:

<Steps>
  <Step title="Open frontend" icon="globe">

  <Step title="Connect wallet" icon="wallet">

    Click "Node Dashboard" in the sidebar
  </Step>
  <Step title="Monitor live" icon="activity">
    See real-time stats: stake, earnings, job history, slash warnings
  </Step>
</Steps>
